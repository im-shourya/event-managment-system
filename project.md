Club Event Manager
Product Overview
Club Event Manager is a platform for managing technical events conducted by a student club. Instead of maintaining registrations and attendance manually, coordinators should be able to create events, manage participants, track attendance and collect feedback from a single platform.
Core Requirements
Student registration/login.
Admin/coordinator login.
Create and edit events.
Event registration.
View registered participants.
Attendance management.
Event status:
Upcoming
Ongoing
Completed
Feedback collection.
Event statistics dashboard.
Optional Features
QR-based attendance
Certificate generation
Email notifications
Event calendar
